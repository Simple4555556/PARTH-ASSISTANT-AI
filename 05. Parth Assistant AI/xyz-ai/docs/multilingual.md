# Multilingual Engine Documentation — PARTH ASSISTANT AI

## Supported Languages (11 Indian Languages + Hinglish)

1. **English (`en`)**
2. **Hindi (`hi` - हिन्दी)**
3. **Tamil (`ta` - தமிழ்)**
4. **Telugu (`te` - తెలుగు)**
5. **Marathi (`mr` - मराठी)**
6. **Bengali (`bn` - বাংলা)**
7. **Gujarati (`gu` - ગુજરાતી)**
8. **Punjabi (`pa` - ਪੰਜਾਬੀ)**
9. **Kannada (`kn` - ಕನ್ನಡ)**
10. **Malayalam (`ml` - മലയാളം)**
11. **Urdu (`ur` - اردو)**

---

## Features

- **Script Detection**: Detects Devanagari, Tamil, Telugu, Bengali, Gujarati, Gurmukhi, Kannada, Malayalam, and Perso-Arabic scripts automatically.
- **Hinglish Support**: Recognizes mixed Hindi-English phrases naturally (e.g. *"Rahul ki attendance check karo"*, *"Mujhe overall attendance dekhni hai"*).
- **Session Language Memory**: Language choice persists across multi-turn chat sessions.
- **UI Selector Dropdown**: Users can select preferred language directly from the Navbar or AI Assistant drawer.
